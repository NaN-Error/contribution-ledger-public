# Security and privacy

Use this experimental application on localhost. Do not expose the personal
Windows installation to the internet or use its simulations as real payouts.

Do not put tokens, passwords, database dumps, captured private source, personal
reports or screenshots in issues, commits, pull requests, build artifacts or logs.
Use synthetic reproduction data. Fine-grained GitHub tokens should have only
selected repository read permissions. Revoke a token on GitHub if it is exposed;
disconnecting the application preserves already captured reports.

For a suspected vulnerability, use this repository's **Security → Report a
vulnerability** private reporting feature. Do not publish exploit details or
secrets in a public issue. If private reporting is unavailable, wait for a private
reporting channel rather than posting sensitive data publicly.

The source and release manifests establish file integrity; they are not an
independent security certification. Review third-party licenses before reuse.
